# macOS 1.1 额度显示预览版

每个已保存账号显示 **5 小时 / 7 天剩余百分比**、进度条、本机时区的重置时间以及刷新状态。

- 打开主窗口后查询；主窗口可见且未最小化时，约每 5 分钟自动刷新。支持单个、全部刷新和停止，手动查询冷却为 30 秒。
- 查询和切换独立：使用账号本机钥匙串备份的 access token；当前账号优先使用身份匹配的最新本机登录。不会退出或重启 Codex，不改当前登录文件。
- 官方 CLI 在独立的 0700 临时 CODEX_HOME 中以 `ephemeral` 存储模式运行，使用实验性 `chatgptAuthTokens` 与 `account/rateLimits/read`。不向子进程传递 refresh token，不执行模型请求、续期或额度重置。
- 过期登录需要更新登录备份或重新添加；不兼容的官方 CLI 会提示更新。缺失/未知窗口显示「—」，不把缺失值当成满额；按实际窗口长度 300 / 10080 分钟匹配，优先 `rateLimitsByLimitId.codex`。
- 查询失败保留上次结果并标记。到重置时间、超过 5 分钟或系统时间回拨时标记待刷新，不猜测自动恢复到 100%。
- 额度只存在内存中。令牌不放进参数、环境变量、元数据或日志。取消、超时、异常退出后清理自己的子进程与临时目录。
- 与旧版共用相同 Bundle ID、钥匙串服务和本机账号列表；不会迁移或删除账号。第一次访问保存凭据时，如有 macOS 确认，请核对应用名称。

## 安装

下载 Mac 额度预览版 ZIP，解压，将「栖言 Codex 账号.app」放到应用程序目录；更新时先退出旧版切换器。支持 Apple Silicon、macOS 14+。使用 ad-hoc 签名，未做 Developer ID 公证；按系统提供的审阅/打开流程处理来源提示。

仅展示测试数据可运行 `--demo`；`--self-test` 在临时目录运行虚构数据测试，附加 `--keychain-test` 只使用随机命名的独立测试钥匙串服务。测试不读取或切换真实账号。
