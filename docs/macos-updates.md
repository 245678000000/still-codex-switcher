# macOS 自动检查更新

从 **1.2.0-preview.1** 开始提供。旧版还没有检查器，需要先手动下载安装一次本版；之后新版可在应用内提示。

## 使用入口

- 应用菜单「栖言 → 检查更新…」。
- 右上角菜单栏图标 →「检查更新…」。
- 主窗口「偏好与说明 → 软件更新」。
- 自动发现新版时，主窗口顶栏显示「有新版本」，点击查看说明。

## 检查与下载

- 默认开启自动检查：每次启动查询一次；持续运行时每 12 小时检查一次。重复手动检查冷却 60 秒，检查期间去重，不阻塞主线程。
- 可以关闭自动检查，关闭后手动检查仍可用；开关与上次成功检查时间保存在本机应用偏好中。
- 预览构建默认接收预览版；关闭「接收预览版本」后只提示正式发布。正式构建默认只检查正式版。
- 使用语义化版本比较，正确区分 `1.10.0` 和 `1.2.0`、`preview.10` 和 `preview.2`，以及同版本的预览版与正式版。不提示降级或相同版本。
- 只接受固定仓库 `245678000000/still-codex-switcher` 中、标签为 `macos-v…` 且包含 `Codex-Account-Switcher-macOS.zip` 已上传资源的发布，排除草稿、Windows 标签和历史混合平台 `v…` 标签（后者可能携带旧的 Mac 安装包）。后续 Mac 正式版也使用 `macos-v版本号` 标签。
- 网络错误或 GitHub 限流会显示检查失败，不当作「已是最新版」。只在收到并校验版本列表后判断是否有更新。
- 点击「查看新版 / 下载…」才打开 GitHub 发布页。**此功能自动检查和提示，不自动下载安装、不替换应用、不退出 Codex 或切换器。**下载 ZIP 后先退出旧版切换器，再替换应用程序中的 App；账号库和钥匙串继续沿用。

## 隐私与请求边界

检查器仅匿名请求 GitHub 公开 Releases API，不读取或发送账号、邮箱、登录令牌、钥匙串或当前 Codex 资料。会话不保存 cookie、HTTP 凭据或磁盘缓存。使用 HTTPS，拒绝 API 重定向，固定请求本仓库的前 3 页，每页最多 100 条、4 MB，并设置请求超时。版本说明按纯文本展示，不执行网页或脚本；下载入口限定为本仓库 GitHub 发布页。

官方接口说明：[GitHub Releases API](https://docs.github.com/en/rest/releases/releases#list-releases)。本功能不依赖 GitHub 登录、API Token、Sparkle 或第三方更新 SDK。

## 开发与验证

`--self-test` 包含合成版本、渠道、URL、网络错误、频率、取消和偏好持久化测试；不读取真实账号。`--update-check-test` 单独访问公开版本列表并模拟旧版比较，在创建账号模型之前退出。`--render PATH --settings --update-demo` 使用虚构的新版本提醒离屏渲染；`1.3.0-preview.1` 仅为界面演示，不代表已发布。

本版仍采用 ad-hoc 签名，未做 Developer ID 公证。更新检查不更改系统应用验证设置。

后续发布时同步更新 `Info.plist` 的 `CFBundleShortVersionString`、递增 `CFBundleVersion`，并把 `StillUpdateVersion` 设置为完整版本（含预览后缀）。创建匹配的 `macos-v版本号` Release，上传同名 Mac ZIP 后再公开；预览版同时勾选 prerelease，正式版去掉预览后缀和该标记。
