# 账号诊断（基础版）

Mac 与 Windows 的「账号诊断」为手动、逐账号检查入口。默认不发请求，点击后确认才运行。

## 本版检查

1. 所选账号与本地凭据身份匹配。优先使用身份一致的当前登录资料，否则使用已保存的加密备份。
2. 独立官方 CLI 的 `initialize` / `account/login/start`（仅 access token）协议。
3. `account/rateLimits/read`：官方额度接口返回状态及 5 小时、7 天剩余额度。窗口缺失显示未知，余额为零提示等待重置。
4. `model/list`：最多四页，每页最多 100 条，重复游标提前结束并标记不完整。目录可能来自缓存，只表示返回了模型标识，不代表实际推理验证。

## 边界

- 基础诊断不发送聊天消息，不启动 thread/turn，不触发预热；不切换、退出桌面 Codex，不操作 VS Code 登录。
- 不刷新或回写凭据。访问令牌需刷新时停止并提示更新备份。
- 本次任务持有账号操作锁；运行时暂停本实例的其他账号操作与额度刷新。既有自动预热设置保持原样。
- 使用独立临时 HOME、CODEX_HOME 和数据库目录。访问令牌只经 stdin 进入官方 CLI；不写 auth.json，不使用 shell 拼接执行命令。
- 总超时 45 秒；可取消；结束后关闭自有子进程并删除自己的 UUID 临时目录。没有自动重试。
- 结果只在内存中按账号 ID 保留；带时间戳。5 分钟、额度到期或时钟回退后为上次结果。手动重复检查至少间隔 30 秒。
- 只展示预定义错误说明；原始服务端错误、访问令牌和刷新令牌不进入界面或报告。
- 基础检查不产生模型推理用量；官方客户端、独立预热任务及其他工具的用量不在此声明范围。

## 指纹评分尚未接入

本版没有模型指纹评分器或真实模型测试按钮。页面仅说明后续实验功能。

参考项目：<https://github.com/Ikaleio/lm-detector>，审阅版本 `a4ef212df06817e8071acd05f00219f4c9eb2f9a`。未复制其实现或数据进本项目。后续需固定带校验和的数据包、离线评分对照验证，并在每次采样前说明数量及额度消耗。

指纹是参考库内的相似度排序，不是官方风控标志，不证明当前桌面聊天的真实模型身份。此工具不会依据相似度自动切号。

## 验收入口

已确认的测试边界：基础诊断结果、手动检查的确认/取消、结果展示。

- C#：`windows/Tests/DiagnosticsTests.cs`，使用虚构凭据与模拟外部 RPC，覆盖缺失/耗尽/过期额度、分页、重复游标、错误脱敏、令牌刷新停止、取消、超时与清理。
- Swift：`Sources/DiagnosticsTests.swift`，等价核心检查及真实 stdin/stdout 模拟子进程；不连接真实服务。
- Mac：`--render /absolute/path.png --diagnostics`，支持 `--dark`、`--compact`、`--diagnostics-empty`。
- Windows：`--render /absolute/path.png --render-diagnostics`，支持 `--dark`、`--compact`、`--diagnostics-empty`、`--diagnostics-bottom`。
- 所有渲染入口始终使用虚构账号。真实账号与服务端结果留待另行确认。

发布版本：macOS 1.5.0-preview.1 / Windows 1.4.0-preview.1。真实服务端诊断未在本次开发中执行；按用户确认发布并更新 Mac 安装。
