# Windows Token 消费统计

Windows 1.2.0-preview.1，适用 Windows 10/11 x64。

- 左侧「Token 统计」提供今日、近 7 天、近 30 天、全部、每日趋势、模型分布和 CSV 导出。
- 只读 `%CODEX_HOME%\sessions` 与 `archived_sessions`；默认 `%USERPROFILE%\.codex`。不读取 WSL。
- 根据 `originator=Codex Desktop` 区分桌面和插件（桌面自身也可写 `source=vscode`）。排除子代理、分叉继承历史、CLI、来源未知日志。临时预热无持久记录，未计入。
- `total_token_usage` 按会话累计增量计算；重复通知和归档副本去重。回退计数跳过并提示可能不完整，不把累计值逐条相加。没有日期的增量不归到之后的日期。
- 总量 = 输入 + 输出。缓存是输入子集，推理是输出子集；可选类别缺失显示 0（日志未记录）。没有可靠模型名则显示「未知模型」。
- 按事件时间与本地时区计入日历日期；近 7/30 天包括今日，并非官方滚动额度窗口。首条累计记录归入首个观测时间，中途开始的日志早期用量无法按日还原。
- 历史会话可能跨账号继续使用，暂不按账号拆分。Token 数不换算订阅费用，也不表示 5 小时/7 天剩余额度。
- 读取在后台进行；未变化文件复用内存缓存，变化文件重新扫描，本页可见时每分钟刷新。CSV 仅日期与数字，不含邮箱、聊天、项目或会话标识；UTF-8 BOM 便于 Excel 打开。
- 统计没有网络、凭据或 CLI 依赖。原有额度查询是独立功能；本次新增统计不改变账号切换行为。
- 拒绝已识别的链接/reparse point。流式读取上限：4 MiB/行、512 MiB/文件、20,000 文件、目录深度 32；超过或发生读取/计数异常会明确提示可能不完整。尚未完整写出的末行等下次扫描。

## 更新

退出旧切换器，将 ZIP 完整解压到新文件夹，运行 StillCodexSwitcher.exe。账号库沿用 `%LOCALAPPDATA%\StillCodexSwitcher`；不需要复制登录凭据。保留旧程序目录用于回退。此包为自包含 x64，未配置 Authenticode 发布者签名。

## 自检

`self-test.cmd` 只使用虚构账号和日志，验证累计差分、重复数据、模型变更、时区/夏令时、过滤、归档去重、缓存失效、损坏/过大行、取消、尾行和 CSV；另有 Windows DPAPI/ACL 原生检查。

GitHub Windows workflow 渲染虚构的浅色、深色、小窗口、空状态统计页，并验证今日/近 7 天/近 30 天切换与已知总量。截图、自检和 CI 不代表在你的 Windows 电脑上安装，也不代表真实账号登录/切换已验证。
